关注如何把 AI 能力转化为具体用户场景、可控的 Workflow 和可验证的原型。借助 AI Coding 快速搭建 Demo，并结合测试结果判断模型能力边界与产品适用场景。

## 独立项目

### [考研陪伴助手](https://github.com/icemouse0906/kaoyan-ai-companion)

针对同学的备考需求，借助 AI Coding 在约 4 小时内完成微信小程序初版，整合 Todo、番茄钟和大模型文本 API，并交付真实用户试用。

**项目重点：** 需求拆解、Prompt 设计、云函数与 API 串联、快速原型验证。

### [LLM Word 智能排版插件](https://github.com/icemouse0906/thesis-format-addin)

将论文格式要求解析为结构化规则，通过 Office.js 执行文档操作；处理 Word for Mac 的接口兼容与 JS 异步队列问题，并就系统级 Bug 提交英文 Issue，获得微软官方反馈。

**项目重点：** 自然语言需求到确定性执行、独立产品原型、工程兼容问题排查。

### [Context Workspace](https://github.com/icemouse0906/context-workspace)

按“正在做的任务”组织网页的 Chrome 侧边栏扩展：手动保存相关页面、恢复到独立窗口，并在关闭前核对标签归属，避免误关无关页面。已整理真实 Side Panel 人工验收、窄宽布局截图与可加载安装包。

**访问状态：** 当前仓库为私有，源码、安装包和验收链接需获得访问权限。

**项目重点：** 任务切换场景、浏览器权限边界、安全关闭规则、自动化与人工验收互补。

[安装包与试用说明](https://github.com/icemouse0906/context-workspace/releases/tag/v0.2.0) · [真实侧边栏验收](https://github.com/icemouse0906/context-workspace/blob/main/docs/manual-acceptance-B3-2026-10-09/README.md)
